# Reproducing the paper

Every number, table and figure in the manuscript is regenerated by a single script in `src/`.
Run each from the `src/` directory. Expected console output is shown below (mean ± SD over the
ten leakage-free splits, seeds 0–9).

> Numbers are deterministic on the pinned versions in `requirements.txt`. Tiny last-digit
> differences across BLAS/OS builds are normal and do not change any conclusion.

## Table 4 — conformal coverage
```bash
python table4_coverage.py
```
Concrete split-conformal: **78.4 ± 4.8 / 90.4 ± 4.1 / 95.6 ± 4.2** at the 80 / 90 / 95% levels.
SFRC: split **79.0 ± 6.2 / 88.7 ± 5.1 / 95.7 ± 2.1**; normalized **82.5 ± 6.6 / 91.2 ± 3.7 / 96.0 ± 2.6**; Mondrian **80.9 ± 8.5 / 92.2 ± 3.1 / 95.2 ± 3.0**. All variants are near-nominal on both classes.

> Convention: the SFRC conformal radius uses the numpy linear-interpolation quantile of the
> calibration residuals; concrete and the polymer stress test use the exact order statistic
> ⌈(n+1)(1−α)⌉. Both carry the same finite-sample guarantee; this matches the manuscript.

* **Class A (concrete):** ρNE(kNN) = +0.277 ± 0.115 (Holm-significant 9/10); ρNE(iso) = +0.313 ± 0.095 (10/10); far-half MAE > near-half MAE in 9/10 splits → **criterion: INFORMATIVE**.

## Section 4.1 — random-forest-core robustness
```bash
python bestcore_rf.py
```
Replacing the core with a random forest on SFRC leaves the conclusions unchanged:
coverage ≈ 81 / 90 / 94%, ρNE(kNN) = +0.13 ± 0.12, ρNE(iso) = −0.09 ± 0.18 (both span zero).

## Section 5.2 — leakage demonstration (random vs grouped)
```bash
python random_vs_grouped.py
```
Concrete: random split R² = **0.909 ± 0.012** (MAE 3.42) vs grouped R² = **0.855 ± 0.027** (MAE 4.59), Welch p < 0.001.
SFRC: random R² = 0.897 ± 0.030 vs grouped R² = 0.774 ± 0.083. The apparent gain under random splitting is a leakage artefact.

## Section 5.3 — polymer stress test (Class C)
```bash
python classC_polymer.py
```
420 specimens / 32 formulation groups. Grouped R² ≈ 0 vs random R² ≈ 0.99 (largest leakage gap of the three classes);
split-conformal under-covers (≈ 87% at the 95% level) under extreme extrapolation; ρNE positive (≈ +0.29 / +0.25, far-half MAE 230 vs 94 MPa, positive 9/10) but, on only 32 groups, the across-split interval spans zero — **suggestive, not established**.
